Steps to filter out the NA values for all the 5 columns in the csv file:
    Select your data (click anywhere inside it).
    Go to the "Data" tab → click "Filter" (this will add dropdown arrows on the column headers).
    For each of the 5 specific columns:
        Click the dropdown.
        Uncheck everything except for "N/A".
    After filtering all 5 columns, you should now see only rows where each of those 5 columns is "N/A".
    Select those filtered rows, right-click, and choose "Delete Row".
    Then, remove the filter (Data → Filter again).
